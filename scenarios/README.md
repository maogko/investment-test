# シナリオ検証: 「10年前のデータだけで選んでいたら？」

`backtest.py`（リポジトリ直下）は **現在の推奨銘柄** を過去に当てはめるため、
結果を知ったうえで選ぶ **後知恵・生存者バイアス** を含みます。

ここではよりフェアに、**2016年時点のファンダメンタルズだけ** をツールに入力し、
当時の情報で選ばせた推奨を 2016→2026 で保有した場合を検証します。

## 実行

```bash
python scenarios/backtest_2016.py
```

- 入力: `scenarios/snapshot_2016.json`（2016年年央の概算ファンダメンタルズ。
  後に伸びた銘柄も低迷した銘柄も両方含む26銘柄）
- スコアリングは本体と同じ `investment_advisor.scoring` を使用

## 結果（概算）

2016年データで `balanced` が選んだ上位10銘柄を等金額・10年保有:

| 指標 | 結果 |
|---|---|
| 等金額ポートフォリオ | 約 **24x**（年率 ~37%、NVDAの大化けに強く影響） |
| 中央値（典型的な1銘柄） | 約 **4.8x**（年率 ~17%） |
| S&P500（約3.3x）超え | **9/10 銘柄** |
| 100万円 → | 等金額 約2,400万円 / 中央値 約480万円 |

ツールが **下位評価して避けた** “2016年に割安に見えた”銘柄は軒並み市場平均割れ:

| 銘柄 | 2016→2026 |
|---|---|
| AT&T (T) | 0.6x（−43%） |
| Wells Fargo (WFC) | 1.6x |
| Exxon (XOM) | 1.7x |
| IBM | 2.1x |

## 解釈と注意

- **良い面**: 後知恵を排除しても、品質・成長・割安・健全性で絞る方針は、
  結果的に勝ち組を多く拾い、典型的な“バリュートラップ”を避けられていた。
- **正直な注意点**:
  - 平均(24x)はNVDA1銘柄(188x)に大きく依存。**中央値(4.8x)が現実的な目安**。
  - 2026年6月はAI主導でバリュエーションが高い局面。出遅れ株も上振れしており、
    別の時点では中央値はより低くなり得る。
  - 2016年のファンダメンタルズ・株価はいずれも **概算の再構成** であり、
    厳密なポイントインタイム・データではない。
  - ユニバースに含めたのは2026年も存続する銘柄のみ（倒産・上場廃止は不在）。
    真に公平な検証ではそうした銘柄も母集団に含める必要がある。
  - **過去の実績は将来を保証しない。** 分散・積立・余裕資金が大前提。
