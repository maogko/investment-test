# 初心者向け 長期投資スクリーニングツール

最新の株価・財務データ（[yfinance](https://github.com/ranaroussi/yfinance) 経由・**無料/APIキー不要**）をもとに、
**3年以上の長期保有**に向いた銘柄を自動でスコアリングし、**推奨理由と注意点つき**で提案する CLI ツールです。

> ⚠️ **免責**: 本ツールは情報提供・学習目的の参考情報です。投資勧誘や個別銘柄の投資助言ではなく、
> 将来の成果を保証しません。投資は元本割れのリスクを伴います。最終判断はご自身の責任で、
> 余裕資金・分散・長期の積立を基本に行ってください。

## できること

- 大型・優良銘柄のユニバース（または任意のティッカー）を最新データで分析
- 長期投資で報われやすい **6 ファクター**で 0〜100 点に採点
  - 収益性 / 財務健全性 / 成長性 / 割安度 / 安定性 / 勢い
- **リスク許容度プロファイル**（安定重視 / バランス / 成長重視）で重み付けを変更
- 上位銘柄に **「なぜ買い候補か」「どこに注意すべきか」** を日本語で提示
- 投資金額を指定すると、スコア加重の**配分イメージ**も表示

## セットアップ

```bash
pip install -r requirements.txt   # yfinance（最新データ取得に使用）
```

> `yfinance` を入れない／ネットに繋がらない場合でも、同梱のスナップショット（概算データ）で動作します。

## 使い方

```bash
# 既定ユニバースをバランス型で診断
python advisor.py

# 安定重視（守り）で上位3件
python advisor.py --profile conservative --top 3

# 任意の銘柄を指定（日本株は末尾に .T 例: トヨタ=7203.T）
python advisor.py --tickers AAPL MSFT 7203.T

# 100万円の配分イメージを表示
python advisor.py --amount 1000000

# ネット不要（同梱データのみ） / JSON出力
python advisor.py --offline
python advisor.py --json
```

### 主なオプション

| オプション | 説明 | 既定 |
|---|---|---|
| `--tickers` | 対象ティッカー（複数可） | 既定ユニバース20銘柄 |
| `--profile` | `conservative` / `balanced` / `aggressive` | `balanced` |
| `--top` | 表示する上位件数 | `5` |
| `--amount` | 配分イメージを出す金額 | なし |
| `--offline` | ネット接続せず同梱データを使用 | off |
| `--refresh` | キャッシュを無視して取り直す | off |
| `--cache-hours` | キャッシュ有効時間（時間） | `24` |
| `--json` | JSON形式で出力 | off |

## データの取得とキャッシュ

取得は次の優先順位で行われ、結果の出所はレポート冒頭の「データの出所」に表示されます。

1. **キャッシュ** … `.cache/latest.json`（既定24時間有効。`--refresh` で無視）
2. **ライブ取得** … yfinance で Yahoo Finance から最新値を取得（無料・APIキー不要）
3. **スナップショット** … `investment_advisor/snapshot.json`（オフライン/失敗時のフォールバック。概算値）

## スコアリングの考え方

各銘柄を 6 ファクターで 0〜100 点に正規化し、プロファイル別の重みで総合点を算出します。

| ファクター | 評価指標 | 長期投資での意味 |
|---|---|---|
| 収益性 | ROE・純利益率 | 稼ぐ力。複利で価値を積み上げる源泉 |
| 財務健全性 | 負債比率・流動比率・FCF利回り | 不況耐性。倒産・希薄化リスクの低さ |
| 成長性 | 売上成長率・利益成長率 | 将来の価値増加の余地 |
| 割安度 | PER・PBR | 割高づかみの回避（赤字は最低評価） |
| 安定性 | ベータ・配当利回り・時価総額 | 値動きの穏やかさ。保有を続けやすさ |
| 勢い | 過去1年リターン | 市場評価の方向（長期では補助的に小さく加重） |

欠損している指標は中立（50点）として扱い、レポートに「データ欠損」として明示します。

## 構成

```
advisor.py                      CLI エントリポイント（レポート出力）
investment_advisor/
  ├─ universe.py                既定の銘柄ユニバース
  ├─ datasource.py              取得層（キャッシュ → ライブ → スナップショット）
  ├─ scoring.py                 ファクター採点と推奨理由の生成
  └─ snapshot.json              フォールバック用データ（概算）
tests/test_scoring.py           ユニットテスト
```
